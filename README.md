# Pollution_Arrhythmia_BCN

Contains the code for the analysis of the manuscript: "Association between air pollution and arrhythmias in patients with heart disease: impact of the implementation of a low-emission zone in the city of Barcelona".

The repository is separated in two different quarto documents:

- `Analysis_Pollution_Arrhythmia.qmd`: contains the code for the main analysis of the association between air pollution and arrhythmias in the city of Barcelona.

- `Analysis_LEZ.qmd`: contains the code for the main analysis of the impact of the low-emission zone (LEZ) on contaminants and arrhythmia incidence in the city of Barcelona.

Data is not available due to privacy restrictions.
